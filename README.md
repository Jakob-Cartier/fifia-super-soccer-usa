# USA National Team — Roblox FIFA Super Soccer

A responsive team website for the custom USA National Team in Roblox FIFA Super Soccer.

## Add the player headshots

Upload the four headshots into `assets/players/` and use one of these filename sets:

- `kayden.jpg` (or `.jpeg`, `.png`, `.webp`)
- `brycen.jpg` (or `.jpeg`, `.png`, `.webp`)
- `tessa.jpg` (or `.jpeg`, `.png`, `.webp`)
- `ruffles.jpg` (or `.jpeg`, `.png`, `.webp`)

The website checks the supported extensions automatically. Keep filenames lowercase. The roster cards use a designed placeholder until a matching image is found.

Recommended image dimensions: portrait 3:4 ratio, ideally 600 × 800 pixels or larger. The card uses `object-fit: cover`, so leave a little space around the head and shoulders.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. GitHub will show the published website URL in Pages settings.

To use a Namecheap domain later, add the custom domain in GitHub Pages settings, then add the DNS records GitHub specifies in Namecheap. Enable HTTPS once DNS verifies.
