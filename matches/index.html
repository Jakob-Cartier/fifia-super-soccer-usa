How match updates work

This website uses GitHub Pages, so the scoreboard is updated when team staff publish changes to assets/match-data.js. During a match, staff can update the score, clock, and event list there, commit the change, and visitors can refresh this page to see the published feed. No scores or events are generated automatically.
